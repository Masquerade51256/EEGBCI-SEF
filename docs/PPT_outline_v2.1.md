### 封面页（1页）
- 标题：急性脑卒中患者MI-EEG跨被试解码的临床异质性分析与自适应策略
- 副标题：基于XWStroke数据集（N=50）的系统性实验验证
- 日期、汇报人

### 背景与问题（2页）

**第1页：临床痛点**
- 脑卒中偏瘫康复 → MI-BCI辅助训练
- 急性期（<7天）患者NIHSS、病灶位置高度异质
- **关键问题**：单被试模型泛化难，群体模型性能被异质性拖垮

**第2页：数据集与实验设计**
- XWStroke数据集：N=50急性脑卒中，32 EEG + 2 EOG，500Hz，4s epoch
- **3个标签体系**标准（LR / 健患侧 / Aff+Align）
- 严格**StreamingLOSO**（无数据泄漏）

### 核心实验结果（4-5页）

**第5页：全人群基线**
- 表格：Task A 49.63% → Task B 50.29% → Task C 51.46%
- 统计结果：Task C vs A 差值+1.83%, p=0.062, d=0.270
- **视觉设计**：Task C用红色高亮，标注"趋势性提升"而非"显著"

**第6页：分层分析——哪些患者受益？**
- 病灶位置：Subcortical +3.6% vs Cortical -3.6%
- NIHSS：中度 +4.0% vs 重度 -5.5%
- 瘫痪侧：Right-Left混杂者 +3.4%
- 病程：早期 +3.5%
- **关键发现**：标签改进对"受损较轻、病灶较深"的患者最有效

**第7页：CleanC子集（N=14）机制验证**
- 无伪迹患者子集：Task A 50.57% → Task C 52.29% (+1.72%)
- 伪迹患者：Task A 48.30% → Task C 50.15% (+1.85%)
- **解读**：标签改进的价值是普适的，但伪迹本身才是性能天花板的主因

**第8页：10人子集与统计稳健性**
- Task A 46.80% → Task C 52.50% (+5.70%)
- Cohen's d = 0.600（中等效应量）
- **新内容**：Subset-20代表性设计（按病灶、NIHSS、瘫痪侧、伪迹分层）
  - 目的：保留全人群异质性，加速实验迭代
  - Baseline Task A ~49.08%, Aff+Align diff ~+1.97%（与全人群趋势一致）

### 方法探索（2页）

**第9页：路线A — 域自适应（DANN）**
- 动机：用对抗训练消除跨被试差异
- 问题发现：stroke_location作为domain label错误（与MI模式耦合）
- 修正：改用ParalysisSide（左/右偏瘫）+ domain weight 0.05
- 当前状态：Subset-20诊断实验运行中

**第10页：路线B — 临床自适应框架**
- 核心思想：不追求"抹除差异"，而追求"按差异分组适应"
- 具体方案：
  1. **动态源域选择**：按临床分组（病灶位置/NIHSS/病程）为每个测试患者选择最相似的源域子集
  2. **条件特征提取**：用临床元数据（NIHSS、病灶侧）作为辅助输入门控特征表达
- 预期优势：可解释 + 临床可落地

### 防御性Q&A预准备（1页，可选放入附录）

**第11页：面对导师/评审的3个必答问题**

**问题1："为什么只有51.46%，远低于Bun25的97.43%？"**
- 协议差异：Bun25的"LOSO"可能是50次随机划分（文献核验标注"定义不明"）
- 公平基准：Wan26h严格LOSO = 66.56%
- 价值定位：我们不与宽松协议比分数，与严格基准比可解释性

**问题2："健患侧标签不是新概念，创新点在哪？"**
- 首次在急性卒中严格LOSO场景中系统验证
- 配合半球对齐 + 分层分析 + 临床变量调节
- 文献确认空白 = "把患者特征真正引入建模"

**问题3："2-3%提升值得发表吗？"**
- 卒中跨被试LOSO的2-3%是困难场景下的真实进步
- 可解释的临床分组机制 > 不可解释的高分
- 若受益亚群提升达5-8%，足以支撑TNSRE/JBHI

### 结论与展望（1-2页）

**第14页：核心结论**
1. 急性卒中MI-EEG的跨被试LOSO基线确实低（~50%），这是**临床异质性的真实反映**
2. 健患侧标签+半球对齐带来**1.83%趋势性提升**，在特定亚群中可达3-6%
3. **真正的创新机会**：将患者临床特征引入建模（自适应分组），而非单纯优化分类器

**第15页：论文定位**
- **目标期刊**：TNSRE（神经康复应用）或JBHI（健康信息学）
- **核心卖点**：
  - "首个"将卒中患者临床变量（病灶、NIHSS、病程）系统引入跨被试MI解码的工作
  - 从"为什么模型表现差"出发，给出"不同患者需要不同策略"的可解释答案
- **对标文献**：Wan26h是方法基准，我们的差异在于临床驱动的自适应

## 视觉设计建议

### 竞对格局地图（第3页）
- 使用二维散点图，X轴"协议严格程度"，Y轴"准确率"
- 用不同颜色区分：宽松协议（灰色）、严格LOSO（蓝色）、我们的方法（红色）
- 每个点旁标注论文名和关键协议特征
- 底部加粗文字："我们的目标不是最高准确率，而是在最严格协议下给出可解释的提升"

### 分层分析（第6页）
- 使用瀑布图或分组柱状图
- 横轴：亚群分类（病灶位置/NIHSS/瘫痪侧/病程）
- 纵轴：Task C vs Task A的差值（%）
- 正值用绿色，负值用红色，直观显示"谁受益、谁受损"

- 3个问题分3栏，每栏：问题（大字）→ 3层回答（要点）
- 背景色用浅灰，与正文页区分，提示"这是备用/防御内容"
