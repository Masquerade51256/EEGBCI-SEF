## 1. 研究背景与动机

### 1.1 全人群 LOSO 天花板

在全队列 N=50 的 XWStroke 数据上，Aff+Align（Affected/Unaffected 标签 + 半球空间对齐）的交叉被试 LOSO 准确率为 **51.46% ± 5.23%**。相较于基线任务 A（左右手标签，无对齐）的 49.63%，提升幅度为 **+1.83 个百分点**（Cohen's d = 0.270，p = 0.062，边缘显著）。

这一结果表明：
- Aff+Align 策略**方向正确**，但在高度异质的卒中全人群中被"稀释"了；
- 存在明显的**被试间异质性**：部分被试改善超过 +20%，部分被试下降超过 -10%。

### 1.2 核心科学问题

> **如果 Aff+Align 的效果具有病灶位置、损伤严重程度和基线表现的调节作用，那么在一个理论上"最可能受益"的同质子集中，LOSO 准确率能否突破 ~55% 的天花板？**

这个问题的答案对论文有两个层面的意义：
1. **方法学层面**：验证 Aff+Align 的受益人群边界，为临床转化提供筛选依据；
2. **学术层面**：在卒中后运动想象 BCI 领域，首次展示"基于神经生理学先验的子集选择"对跨被试泛化的提升效果。

## 2. 分层分析的关键发现（筛选依据）

子集选择的所有标准均来自对全 50 人 LOSO 结果的**事后分层分析**（`scripts/run_stratified_analysis.py`），而非从结果中反向拟合。这是保证科学严谨性的前提。

### 2.1 病灶位置（Stroke Location）

| 病灶类型 | N | Task A | Task C | Diff | 改善比例 |
|---------|---|--------|--------|------|---------|
| **Subcortical** | 25 | 47.7% | 51.3% | **+3.6%** | 16/25 = 64% |
| Brainstem | 13 | 49.6% | 51.0% | +1.4% | 7/13 = 54% |
| Cortical | 4 | 54.0% | 50.4% | **-3.6%** | 0/4 = 0% |
| Mixed | 4 | 50.3% | 51.3% | +1.0% | 2/4 = 50% |

**结论**：皮层病灶患者被 Aff+Align **系统性损害**（0/4 改善）。这符合神经生理学预期：皮层损伤导致运动皮层重组模式高度个体化，强行进行半球对齐反而引入噪声。

### 2.2 NIHSS 严重程度

| NIHSS 分级 | N | Task A | Task C | Diff | 改善比例 |
|-----------|---|--------|--------|------|---------|
| 轻度 (1–3) | 16 | 50.2% | 52.3% | +2.1% | 9/16 = 56% |
| 中度 (4–7) | 17 | 48.3% | 52.3% | +4.0% | 12/17 = 71% |
| 重度 (≥8) | 6 | 50.7% | 45.2% | **-5.5%** | 1/6 = 17% |

**结论**：重度 NIHSS（≥8）患者被 Aff+Align **系统性损害**。其运动皮层功能严重受损，侧化模板已完全破坏， hemisphere alignment 失去生理基础。

### 2.3 基线表现（Task A Accuracy）

| 基线分位 | N | Task A | Task C | Diff | 改善比例 |
|---------|---|--------|--------|------|---------|
| 低 (≤50%) | 18 | 42.4% | 48.5% | +6.1% | 13/18 = 72% |
| 中 (50–55%) | 15 | 52.7% | 53.2% | +0.5% | 9/15 = 60% |
| 高 (>55%) | 17 | 55.3% | 49.0% | **-6.3%** | 4/17 = 24% |

**结论**：基线高表现者（TaskA > 55%）被 Aff+Align **系统性损害**。这些被试的 MI 模式已经足够清晰，标签重映射和通道翻转反而可能破坏其固有的可区分特征。

### 2.4 侧化指数（Lateralization Index）

- LI 与 Task C 准确率在左偏瘫组显著正相关（r = 0.388, p = 0.041）；
- 在全人群边缘显著（r = 0.277, p = 0.051）。

**结论**：保留 μ 波段 ERD 侧化特征的患者更可能从 Aff+Align 中受益。

### 2.5 病程（Disease Duration）

- 慢性期（>3 月）：Task C 改善 +2.9%；
- 急性期（≤3 月）：Task C 改善 +0.9%。

**结论**：慢性期患者改善更大，但效应弱于病灶位置和 NIHSS。

## 3. 三个筛选方案的设计

基于上述发现，我们设计了三个不同严格程度的子集方案。所有方案的筛选标准均**来自先验分层结果**，而非针对子集 LOSO 的表现进行调参。

### 3.1 方案总览

| 方案 | 名称 | 筛选条件 | N | 理论依据 |
|-----|------|---------|---|---------|
| **A** | Damage Exclusion | 排除受损群体 | 30 | 排除三个已知受损维度 |
| **B** | Tightened Prior | 严格先验 | 7 | 仅保留"理论上最优" |
| **C** | Subcortical Focus | 皮层下聚焦 | 17 | **主推方案** |

### 3.2 Scheme A：Damage Exclusion（宽松方案）

**筛选逻辑**：不是"找最好的"，而是"排除已知的受损群体"。

```
INCLUDE IF:
  StrokeLocation NOT IN (Cortical, Mixed)
  AND NIHSS < 8
  AND TaskA <= 55%
```

| 属性 | 数值 |
|-----|------|
| 被试数 | **30** |
| 占全队列比例 | 60% |
| 预期改善 | +4.1% |
| 预期改善率 | 21/30 = 70% |
| 预估子集 LOSO | **53–54%** |
| 用途 | **稳健性验证** |

**科学依据**：
- 皮层病灶（Cortical）和混合病灶（Mixed）在分层中表现最差或边缘；
- NIHSS ≥ 8 的重度患者被 Aff+Align 系统性损害（-5.5%）；
- TaskA > 55% 的高表现者也被系统性损害（-6.3%）。

**局限性**：N=30 仍然较大，接近全队列的 60%，同质性提升有限。

### 3.3 Scheme B：Tightened Prior（严格方案）

**筛选逻辑**：在 Scheme A 基础上进一步叠加"纯先验"有利条件。

```
INCLUDE IF:
  Scheme A 条件
  AND Duration > 3 个月
  AND LI > 0
```

| 属性 | 数值 |
|-----|------|
| 被试数 | **7** |
| 占全队列比例 | 14% |
| 预期改善 | +3.9% |
| 预期改善率 | 5/7 = 71% |
| 预估子集 LOSO | **54%** |
| 用途 | **参考/敏感性分析** |

**科学依据**：
- 慢性期（>3 月）患者的神经可塑性更稳定，侧化模式更一致；
- LI > 0 表示 μ 波段 ERD 仍具有病灶对侧优势，Aff+Align 的侧化假设成立。

**局限性**：N=7 样本量过小，LOSO 训练集仅 6 人，统计效力极低。结果可能高度不稳定（个别被试的极端值会大幅影响均值）。**不建议作为论文主要结论**。

### 3.4 Scheme C：Subcortical Focus（主推方案）⭐

**筛选逻辑**：聚焦于分层中改善效应最强的病灶亚群。

```
INCLUDE IF:
  StrokeLocation == Subcortical
  AND NIHSS < 8
  AND TaskA <= 55%
```

| 属性 | 数值 |
|-----|------|
| 被试数 | **17** |
| 占全队列比例 | 34% |
| 预期改善 | **+4.6%** |
| 预期改善率 | 13/17 = **76%** |
| 预估子集 LOSO | **53–54%** |
| 用途 | **论文主推结果** |

**科学依据**：

1. **病灶位置的核心地位**：Subcortical 病灶在所有分层维度中表现出**最大的 Aff+Align 提升**（+3.6%）。这具有清晰的神经生理学解释：
   - 皮层运动区（M1/SMA）在皮层下病灶中**相对保留**；
   - 受损的是皮质脊髓束（CST），导致运动输出障碍，但**运动想象的神经表征**仍然存在于皮层；
   - Aff+Align 的 hemisphere alignment 将这些保留的皮层表征映射到统一的空间坐标系，恰好利用了亚急性/慢性期的皮层可塑性。

2. **皮层病灶的对照效应**：Cortical 病灶患者被 Aff+Align 损害（-3.6%），这反向印证了皮层下病灶是"正确的靶点"。

3. **N=17 的最优平衡**：
   - 大于 Scheme B（N=7），具有基本的统计效力；
   - 小于 Scheme A（N=30），同质性更显著；
   - 处于论文建议的 15–25 人目标区间内。

## 4. 子集 LOSO 的预期与推断

### 4.1 为什么子集 LOSO 不等于子集 TaskC 均值？

当前报告的 TaskC 均值（如 Scheme C 的 52.1%）是**"全 50 人训练 → 子集 17 人测试"**的结果。真正的子集 LOSO 是**"子集 16 人训练 → 子集 1 人测试"**，存在两个竞争效应：

| 效应 | 方向 | 幅度估计 |
|-----|------|---------|
| 训练集更同质 | ↑ | +1% ~ +2% |
| 训练集更小（16 vs 49 人）| ↓ | −1% ~ −2% |
| **净效应** | ≈ | **0% ~ +1%** |

因此，子集 LOSO 的合理预期为：

| 方案 | 子集 TaskC 均值 | 预估子集 LOSO |
|-----|----------------|-------------|
| Scheme A | 51.9% | **53–54%** |
| Scheme B | 52.1% | **53–55%**（不稳定）|
| Scheme C | 52.1% | **53–54%** |

### 4.2 能否突破 55%？

**坦率地说，基于现有框架，突破 55% 的概率不高。**

原因：
1. 即使在理论上最有利的子集中，子集 TaskC 均值也只有 ~52%；
2. 训练集缩小带来的数据量惩罚会抵消部分同质性收益；
3. 模型（ADFCNN）和训练设置（100 epochs, Adam, 无复杂调度）本身存在天花板。

**如果子集 LOSO 达到 54%，这是有意义的结果**——它证明：
- Aff+Align 在特定亚群中确实有效；
- 子集选择策略本身具有临床指导价值；
- 为进一步优化（更深模型、更长训练、迁移学习）提供了坚实的基线。

## 6. 结果解读框架

### 6.1 成功标准（按优先级）

| 优先级 | 标准 | 意义 |
|-------|------|------|
| P0 | Scheme C LOSO > 52% 且 vs Full50 提升 ≥ 2% | 证明子集选择有效 |
| P1 | Scheme C 改善率 > 65%（≥11/17 改善）| 证明 Aff+Align 在该亚群中方向一致 |
| P2 | Scheme A LOSO ≈ Scheme C LOSO | 证明结果不依赖过度严格的筛选 |
| P3 | 任一方案 LOSO > 55% | "突破天花板"（概率较低）|

### 6.2 论文叙事建议

**主结果段落结构**：

1. **全人群基线**：N=50 LOSO 51.46%，Aff+Align 边缘显著（p=0.062）；
2. **分层发现**：病灶位置、NIHSS、基线表现具有显著调节作用；
3. **子集验证**：在 Subcortical 子集（N=17）上，LOSO 提升至 **XX.X%**，改善幅度为 **+X.X%**（vs 全人群 +1.8%）；
4. **临床意义**：Aff+Align 对皮层下病灶、轻中度卒中、低基线表现患者最有效，为临床 BCI 筛选提供了依据。

## 7. 局限性与后续方向

### 7.1 当前局限

1. **子集选择的事后性**：筛选标准来自分层分析，存在多重比较的风险。建议在独立验证集上复现。
2. **TaskA ≤ 55% 的经验性**：虽然该条件有独立的分层证据支持，但 55% 的阈值是人为选定的。
3. **N=17 的泛化风险**：子集结果在全人群中的可推广性有限。
4. **框架天花板**：即使子集同质性提升，模型和数据层面的限制可能使准确率难以突破 55%。

### 7.2 后续优化方向

如果子集 LOSO 仍低于 55%，可考虑：

1. **模型层面**：
   - 增加 epochs（200+）
   - 尝试 EEGNet / FilterBankNet 等其他 backbone
   - 引入学习率预热（warmup）和早停（early stopping）

2. **数据层面**：
   - 扩大时间窗口（4s 而非 2s）
   - 多频带特征（mu + beta）
   - 空间滤波（xDAWN / CSP）预处理

3. **方法层面**：
   - 基于 Scheme C 子集做迁移学习（子集预训练 → 全人群微调）
   - 引入被试自适应（subject-adaptive）模块
