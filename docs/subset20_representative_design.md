# Subset-20 Representative Cohort Design

> **Version**: v1.0  
> **Date**: 2026-05-18  
> **Purpose**: Rapid validation subset for method iteration (NOT beneficiary screening)

## Core Principle

This subset is designed for **one purpose only**: to reduce experimental turnaround time while producing results that are **generalizable to the full N=50 cohort**.

It is fundamentally different from CleanC/Scheme C:
- **CleanC/Scheme C**: "Mechanism validation" — screen for the most homogeneous beneficiary subgroup to test neurophysiological hypotheses
- **Subset-20**: "Method iteration" — a miniature version of the full cohort to rapidly test new algorithms

## Usage Protocol

### Step 1: Baseline Validation (MANDATORY)

Before testing any new method on this subset, run the baseline LOSO:

```bash
# Task A: Left/Right labels
python train.py --config configs/experiment/xwstroke_subset20_loso_lr.yaml

# Task C: Affected/Unaffected + Hemisphere Alignment
python train.py --config configs/experiment/xwstroke_subset20_loso_affected_aligned.yaml
```

**Acceptance criteria** for subset validity:
- Task A mean ∈ [47%, 52%]
- Aff+Align improvement ∈ [0%, +4%]
- If these criteria fail, the subset is not representative and should be resampled.

### Step 2: New Method Testing

Only after baseline validation passes:

```bash
# Example: DANN on representative subset
python train.py --config configs/experiment/xwstroke_subset20_dann.yaml
```

### Step 3: Full Cohort Verification

Once a method shows promise on Subset-20:

```bash
# Run on full N=50 for paper-grade results
python train.py --config configs/experiment/xwstroke_full_loso_affected.yaml
```
