# Experiments Directory

This directory contains experiment outputs generated by the training framework.

## ⚠️ Important Notice

**This directory is ignored by Git.** Experiment results should NOT be committed to version control because:

1. They are typically large (model weights, plots, logs)
2. They can be regenerated from code and configuration
3. Git is not designed for binary/large file version control

## Recommended Workflow

### Local Development
Run experiments locally, results will be saved here but not committed:
```bash
python train.py --config configs/experiment/my_exp.yaml
```

### Experiment Tracking (Recommended)
For proper experiment management, consider using:

- **Weights & Biases (WandB)**: https://wandb.ai
- **MLflow**: https://mlflow.org
- **TensorBoard**: https://www.tensorflow.org/tensorboard
- **DVC**: https://dvc.org

### Backup Important Results
If you need to share or backup specific experiment results:

1. **Cloud Storage**: Upload to Google Drive, Dropbox, AWS S3, etc.
2. **Model Registry**: Use Hugging Face Model Hub or similar
3. **Manual Selection**: Copy important results to a separate location

## Directory Structure

When you run experiments, the following structure will be created:

```
experiments/
└── EXPERIMENT_NAME/
    ├── config.yaml              # Saved configuration
    ├── checkpoints/             # Model checkpoints (.pt files)
    ├── logs/
    │   └── training.log         # Training log
    ├── visualizations/          # Plots and figures
    └── results/
        └── results.json         # Final metrics
```

## Cleaning Up

To clean old experiments:

```bash
# Remove all experiments (be careful!)
rm -rf experiments/*

# Or use the provided script (if available)
python scripts/clean_experiments.py --days 30
```

## Reproducibility

To reproduce an experiment, you only need:
1. The code (committed to Git)
2. The config file (can be found in experiment folder or configs/)
3. The dataset (downloaded separately)

Then run:
```bash
python train.py --config path/to/experiment/config.yaml
```
