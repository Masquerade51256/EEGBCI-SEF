# XWStroke 15人子集 LOSO 对照试验方案

## 1. 试验目的

在 XWStroke 数据集的 15 人代表性子集上，通过严格的 LOSO（Leave-One-Subject-Out）跨被试协议，**正面比较两种任务定义的分类效果**：

- **任务 A（基准）**：左手 vs 右手（解剖左右标签）
- **任务 B（功能）**：患侧 vs 健侧（功能侧标签，基于 `participants.tsv` 中的 `ParalysisSide` 自动映射）

核心问题：**在卒中患者跨被试 MI 解码中，将标签从"左右手"改为"患健侧手"是否能提升 LOSO 泛化性能？**

---

## 2. 子集选取策略与理由

### 2.1 选取方法

采用**分层抽样**策略，以 **LOSO 性能** 为主要分层变量，同时控制以下临床维度：

| 分层维度 | 总体分布 (N=50) | 子集分布 (N=15) | 偏差 |
|:---|:---|:---|:---|
| **偏瘫侧** | 左 56% / 右 44% | 左 60% / 右 40% | ≤4% |
| **性别** | 男 78% / 女 22% | 男 73% / 女 27% | ≤5% |
| **NIHSS** | 均值 4.16±2.85 | 均值 3.80±2.11 | 接近 |
| **MBI** | 均值 70.9±18.2 | 均值 74.4±19.3 | 接近 |
| **mRS** | 均值 2.68±1.45 | 均值 2.20±1.47 | 略轻 |
| **LOSO 性能** | 高 42% / 中 26% / 低 32% | 高 33% / 中 33% / 低 33% | **严格三分** |
| **Within-subject 性能** | 高 34% / 中 32% / 低 34% | 高 27% / 中 40% / 低 33% | 接近 |

### 2.2 最终 15 人子集

```
[5, 7, 8, 9, 10, 12, 15, 16, 19, 30, 31, 32, 40, 43, 49]
```

### 2.3 代表性说明

1. **性能覆盖全面**：包含 LOSO 高表现者（sub-10: 57.5%）、中等者（sub-8: 56.5%）和低表现者（sub-49: 42.5%）
2. **临床异质性保留**：NIHSS 1-8，mRS 0-4，病程 1-6 月，年龄 32-74 岁
3. **偏瘫侧平衡**：左偏瘫 9 人（含 sub-15 左利手特例），右偏瘫 6 人
4. **与总体性能一致**：子集 LOSO 均值 50.6% ≈ 总体 50.7%，Within-subject 均值 69.6% ≈ 总体 69.5%

## 3. 实验设计

### 3.1 实验架构

```
┌─────────────────────────────────────────────────────────────┐
│                    15 名被试的子集                             │
│  [5, 7, 8, 9, 10, 12, 15, 16, 19, 30, 31, 32, 40, 43, 49]  │
└───────────────────────┬─────────────────────────────────────┘
                        │
        ┌───────────────┴───────────────┐
        │                               │
   任务 A (左右手)                  任务 B (患健侧)
   label_mapping: "lr"              label_mapping: "affected"
        │                               │
   ┌────┴────┐                   ┌────┴────┐
   │ LOSO x15 │                   │ LOSO x15 │
   └────┬────┘                   └────┬────┘
        │                               │
   per-subject acc               per-subject acc
   overall mean±std              overall mean±std
```

### 3.2 控制变量（两组完全一致）

| 变量 | 任务 A | 任务 B | 说明 |
|:---|:---|:---|:---|
| **被试集合** | 相同 15 人 | 相同 15 人 | 子集 ID 完全一致 |
| **模型** | ADFCNN | ADFCNN | 与既往 50 人 LOSO 基准一致 |
| **预处理** | XWStroke 标准配置 | XWStroke 标准配置 | 降采样 250Hz，4-40Hz 滤波，2s/0.5s 滑窗 |
| **数据增强** | noise + dropout + timewarp (p=0.3) | 相同 | 相同随机种子 |
| **训练 epochs** | 100 | 100 | 与 streaming LOSO 基准一致 |
| **batch size** | 64 | 64 | 利用 14 人合并训练集的大样本优势 |
| **优化器** | Adam, lr=1e-3, wd=0.01 | 相同 | 相同 |
| **学习率调度** | Cosine annealing | 相同 | LOSOTrainer 内置 |
| **随机种子** | 42 | 42 | 确保可复现 |
| **标签映射** | `lr` (0=左, 1=右) | `affected` (0=患侧, 1=健侧) | **唯一差异** |

### 3.3 LOSO 协议

对于每个被试 $i \in \{1, ..., 15\}$：
1. **训练集**：其余 14 名被试的数据合并
2. **测试集**：被试 $i$ 的数据
3. **模型**：从头初始化（不共享权重）
4. **评估**：测试集上的分类准确率

循环 15 次，得到 15 个独立模型的测试准确率。

## 4. 评估指标

### 4.1 主要指标

| 指标 | 公式/定义 | 预期用途 |
|:---|:---|:---|
| **Test Accuracy** | 正确分类样本 / 总测试样本 | 主要比较指标 |
| **Overall Mean ± Std** | 15 次 LOSO 的平均 ± 标准差 | 总体性能对比 |
| **Balanced Accuracy** | (TPR + TNR) / 2 | 考虑类别不平衡（滑窗后可能轻微不平衡） |

### 4.2 次要指标（分层分析）

| 分层 | 分析内容 |
|:---|:---|
| **按偏瘫侧** | 左偏瘫被试 vs 右偏瘫被试，哪种标签在各自群体更优 |
| **按 NIHSS  severity** | 轻/中/重度患者在两种标签下的表现差异 |
| **按 LOSO 性能层** | 高/中/低表现者在任务 B 中是否有系统性提升 |
| **按病程** | 急性/亚急性/慢性患者在两种标签下的差异 |

### 4.3 统计比较

- **配对 t 检验**：同一被试在任务 A 和任务 B 下的准确率差异
- **Cohen's d**：效应量大小
- **95% 置信区间**：均值差异的置信区间

## 7. 预期结果与判读框架

### 7.1 三种可能结果模式

| 结果模式 | 条件 | 结论 |
|:---|:---|:---|
| **模式 1** | 任务 B 均值显著 > 任务 A | 支持"功能侧标签改善跨被试泛化" |
| **模式 2** | 任务 B ≈ 任务 A（差异 < 2%） | 标签重定义对该模型/数据增益有限 |
| **模式 3** | 任务 B 均值 < 任务 A | 功能侧标签在此场景下不适用（需检查映射逻辑） |

### 7.2 更细粒度的判读

即使总体均值无显著差异，以下模式仍有价值：

| 观察 | 含义 |
|:---|:---|
| 任务 B 的 **std 更小** | 功能侧标签降低了被试间方差，更稳定 |
| 低表现者在 B 中被 **抬升** | 功能侧对齐帮助了最难解码的患者 |
| 左偏瘫患者在 B 中 **提升更明显** | 左偏瘫群体的左右模板破坏更严重 |
| 重度患者（NIHSS≥8）在 B 中 **更优** | 高异质性群体更受益于功能侧对齐 |

## 9. 后续扩展方向

1. **通道空间翻转**：若任务 B 更优，可进一步做 hemisphere alignment（将患侧半球统一映射到同一伪侧）
2. **患侧 vs 静息**：若数据允许，提取基线窗口构建第三类任务定义
3. **LOGO 分组**：按 NIHSS 或病程分组，检验标签重定义是否只在特定亚群有效
4. **多模型验证**：在 EEGNet / XWFilterBankNet 上重复对照，确认结果稳健性
5. **50 人全量验证**：若 15 人子集有正结果，扩展至全部 50 人统计验证

---

## 10. 关键注意事项

1. **严格一致性**：两组实验除 `label_mapping` 外，其余所有参数必须一致，任何差异都会混淆因果推断
2. **随机种子固定**：seed=42 确保两组的数据增强、初始化等随机因素一致
3. **模型独立初始化**：每轮 LOSO 的模型必须从头初始化，不能用上一轮权重
4. **标签映射验证**：运行前先用 `scripts/verify_label_mapping.py` 确认患健侧映射正确
5. **类别平衡监控**：滑窗后检查两类样本数是否接近，若某被试出现严重不平衡，需在报告中注明
